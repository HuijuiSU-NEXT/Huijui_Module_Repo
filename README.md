# 🔥 HuiJui 模块仓库 (HuiJui Module Repo)

欢迎来到 **HuiJuiSU NEXT** 官方专属模块聚合库！

本仓库由 GitHub Actions 驱动，全自动扫描、聚合全网优质的开源 KernelSU / Magisk 模块（通过 Topic 标签识别）。
旨在为极客玩家提供最纯净、最新的模块检索体验，彻底告别乱刷野包导致卡开机变砖的烦恼！

## 🚀 如何在 HuiJuiSU NEXT 中使用？
1. 打开 HuiJuiSU NEXT 管理器。
2. 进入「模块仓库」页面。
3. 填入本仓库的专属源地址：
   `https://你的用户名.github.io/你的仓库名/modules.json`
4. 刷新，即刻享受丝滑的模块下载体验！

## ⚠️ 安全警告
- 本仓库仅提供模块链接聚合与检索，不对模块内部代码的安全性与稳定性做绝对担保。
- 刷机有风险，请务必做好数据备份。
- 严禁将本仓库内的任何模块用于黑灰产、外挂等非法用途。
